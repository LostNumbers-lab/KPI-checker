# Social Pulse · KPI Checker

YouTube, Facebook, Instagram, X의 실제 계정 관찰 데이터를 표시하는 KPI 대시보드입니다.

## 게시 사이트

- [실제 데이터 대시보드](https://lostnumbers-lab.github.io/KPI-checker/dist/index.html)
- 저장소 루트 Pages 주소도 대시보드로 이동합니다.

## 데이터 기준

기준일: **2026-10-23 KST**. 최신 재확인: **10:50 KST**. 자동 API 동기화가 아닌 수동 수집 스냅샷입니다. 개별 필드의 수집 시점은 서로 다를 수 있으며 화면·JSON에 범위를 보존합니다.

| 채널 | 실제 관찰값 | 범위 |
| --- | ---: | --- |
| YouTube | Shorts 누적 조회 25 / 구독자 0 | 공개 Shorts 2개 현재 누적. 확정 분석은 10/21까지 24회 |
| Facebook | 조회 477 / 팔로워 1 | 최근 28일 9/25~10/22. 최신 최근7일 웹 조회255 |
| Instagram | 조회 33 / 팔로워 0 | 최근30일, 오늘 제외. 절대 시작·종료일 미표시 |
| X | 게시물 누적 노출109 / 팔로워1 | 전체6개 게시물 누적, 고유 도달/동영상 재생수 아님 |

총 26개 고유 콘텐츠를 반영했습니다. Facebook 제목 없는 사진도 원자료에 따라 포함합니다. X 자기 스레드 답글1개를 원본 게시물과 구분합니다. 서로 다른 기간·정의의 위 수치를 합산하지 않습니다.

## 집계 원칙

- 난수로 생성하던 조회수·팔로워·게시물과 가상 목표·달성률·추천값을 제거했습니다.
- 미제공 값은 null 및 데이터 없음으로 유지하며, 0으로 대체하지 않습니다.
- 콘텐츠 누적 스냅샷과 일별 발생 활동은 독립 집계입니다.
- YouTube 일별 공식 CSV는 10/21까지, Facebook 페이지 일별 CSV는 9/25~10/23의29행입니다. 마지막 날은 진행 중입니다.
- Facebook 일별 CSV 합계477, CSV 최근7일 합251과 더 나중 웹 최근7일255는 갱신시점이 달라 그대로 보존합니다.
- Facebook 공개 URL ID61595243344343와 보고서 Page ID1287167924491177의 연결은 페이지 투명성 화면에서 확인했습니다.
- 일별 CSV의 보고 시간대가 명시되지 않아 KST 날짜로 재해석하지 않습니다. Instagram·X 일별 발생 자료는 미제공입니다.
- 확인된 UTC 공개 게시일만 KST로 변환합니다. Facebook 게시일은 CSV/화면 표기가 달라 원문을 보존하고 KST 게시일 기간 필터에서는 제외합니다.
- 기간 필터는 차트 원본 보고 날짜와 콘텐츠의 KST 게시일에 적용합니다. 요약 카드는 각각 명시된 원본 기간을 유지합니다.
- 기존 전환수는 구매 전환이 아닌 반응 합계여서 열을 제거했습니다. 좋아요·저장·공유·재게시·댓글은 상세에 구분합니다.
- 동일 KST 주간 자료가 모두 없어 합산 KPI 달성률·직전4주 추천목표는 집계 보류합니다. 사용자가 직접 입력한 목표만 별도 저장합니다.
- channel/content/daily CSV행은 서로 다른 집계 단위이므로 합산하면 중복됩니다. ID는 Excel에서 텍스트로 가져오거나 JSON을 사용하세요.

## 주요 기능

- 실제 채널 스냅샷, 출처와 수집 시각
- 1일/7일/30일/전체 필터, 누락일을 잇지 않는 실제 일별 차트
- 채널 필터, 콘텐츠 검색·정렬·상세 지표
- 확보된 실제 썸네일만 사용, 데모 그림 미사용
- 실제 데이터 JSON 및 채널/콘텐츠/일별 CSV 내보내기
- 가상 목표와 분리된 브라우저 목표 저장

## 실행

Node.js 설치 후 저장소에서 실행합니다. 추가 패키지 설치는 필요 없습니다.

```sh
npm start
```

http://127.0.0.1:4173 에서 확인합니다. dist/는 빌드 없이 정적 호스팅할 수 있습니다. 데이터는 dist/app.js의 DATA에 명시적으로 포함되어 있으며 자동 갱신되지 않습니다.

## 파일

- dist/index.html: 대시보드
- dist/updates.html: 실제 데이터 전환 기록
- dist/app.js: 실제 관찰 데이터, 필터, 목표, 내보내기, 상세 보기
- dist/style.css: 반응형 스타일
- index.html: Pages 루트에서 대시보드로 이동

현재 버전: v2.0.0
