# Social Pulse · KPI Checker

YouTube, Facebook, Instagram, X의 성과를 한 화면에서 확인하는 소셜 KPI 대시보드입니다.

현재 게시 사이트: [Social Pulse](https://social-pulse-kpi-oct23.skp-k-2881.chatgpt.site) (ChatGPT 로그인 필요)

## 실행 방법

Node.js 설치 후 저장소에서 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
npm start
```

브라우저에서 <http://127.0.0.1:4173>을 엽니다. 또는 `node preview.cjs`로 실행할 수 있습니다.

`dist/` 폴더는 빌드 없이 정적 호스팅할 수 있는 완성 파일입니다.

## 주요 기능

- 주간 합산 조회수 목표, 성과 및 달성률
- 주간 목표 입력과 브라우저 저장
- 직전 완료된 최대 4주 평균에 10%를 더하고 100회 단위로 올림한 추천 목표
- 1일, 7일, 30일, 전체 기간 필터 및 채널별 조회수 추이
- 팔로워, 유효 게시물, 조회수, 전환수, 댓글 비교
- 콘텐츠 검색, 성과 정렬, 페이지 이동 및 채널 필터
- 주제별 데모 썸네일 12종, 이미지 확대와 콘텐츠별 성과 확인
- 지표별·콘텐츠별·전체 CSV 다운로드
- 월요일 오전 9시(한국 시간) 정기 알림용 캘린더 파일 다운로드
- 별도 업데이트 기록 페이지 (`updates.html`)

## 데이터 기준

현재 데이터는 **임의의 데모 데이터**입니다. 실제 채널 API는 연결되지 않았습니다.

- 데이터 범위: 2026-08-29 ~ 2026-10-23 (기준일 고정)
- 최초 주간 목표: 10,000회, 해당 주 데모 성과: 12,480회 (124.8%)
- 주간 KPI: 월요일 ~ 일요일, 기준일까지 집계
- 팔로워: 기간 마지막 날의 스냅샷 (채널 간 동일 사용자 중복 포함)
- 유효 게시물: 채널 + 게시물 ID로 중복 제거
- 전환수: 좋아요 + 저장 + 공유 + 리포스트의 반응 횟수, 댓글은 별도 집계
- 썸네일: 실제 게시물 사진이 아닌 로컬 SVG 데모 일러스트
- 전체 CSV의 `content`, `daily`, `goal` 행은 별도 집계 단위입니다. 콘텐츠와 일별 조회수를 함께 합산하면 중복됩니다.

목표는 현재 브라우저의 localStorage에 저장됩니다. 기기 간 동기화와 서버 데이터 저장은 없습니다.
Codex 대화에서 설정한 월요일 자동 알림은 별도 서비스 설정이며 이 저장소를 복제하는 것만으로 생성되지 않습니다. 웹에서는 `.ics` 파일을 내려받아 캘린더에 추가할 수 있습니다.

## 파일 구성

```text
dist/
  index.html           대시보드
  updates.html         업데이트 기록
  app.js               데이터·필터·목표·CSV·썸네일 미리보기
  style.css            반응형 스타일
  thumbnails/          데모 썸네일 SVG 12종
preview.cjs            로컬 정적 서버
create-thumbnails.cjs  썸네일 재생성 스크립트
```

썸네일을 다시 생성하려면 `node create-thumbnails.cjs`를 실행합니다.
